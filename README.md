# UPI Scam Reporting Portal

A web application for reporting and managing UPI and digital payment fraud incidents.

## Features

- Submit a fraud report
- View submitted reports
- View report details
- Search and filter reports
- Update report status
- Delete reports
- Input validation

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON

## Project Structure

- Backend - Server-side code and data
- Frontend - User interface
